# Security Policy

## Reporting a vulnerability

Do not disclose a suspected security issue in a public issue. Use GitHub's private vulnerability reporting for this repository and include a minimal reproduction, affected file or behavior, impact, and suggested mitigation if known.

## Scope

GOP provides prompt-level defenses such as instruction/data separation and safe uncertainty behavior. It cannot enforce external permissions, data isolation, secret management, tool authorization, or model-provider safety policies. Deploy those controls outside the prompt.
